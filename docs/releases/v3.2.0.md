Finale 3.2.0 — Wunschliste als eigener Tab, KI-Funktionen (Auto-Fill, Smart-Cart, Websuche), Wochen-/Monatsberichte und Export/Import als ZIP jetzt auf Web und Android, plus elf Fixes aus zwei vollständigen QA-Durchläufen seit rc.1.

### Gegenüber rc.5

Vier weitere Fixes aus einem zweiten, vollständigen Testdurchlauf über die live laufende Web-App (Chrome-Extension, echte Server-Interaktion statt nur Code-Review):

- **Web: Tagebuch-Lackauswahl verwechselte gleichnamige Lacke** — zwei Lacke mit gleichem Namen/Marke waren im Auswahl-Formular ununterscheidbar; Anhaken des zweiten hob den ersten wieder auf statt einen zweiten Eintrag hinzuzufügen. (#176)
- **Web: Sync-Konfiguration wurde ohne Validierung gespeichert** — unvollständige Zugangsdaten wurden anstandslos übernommen, der Sync schlug dann bei jedem App-Start mit einer kryptischen Fehlermeldung fehl. (#177)
- **Web: Foto-Upload ohne konfigurierten Sync scheiterte mit unerklärtem „401"** — der Foto-Button war immer aktiv, obwohl der Server zwingend Sync oder einen API-Key verlangt. (#180)
- **Web: Header-Zähler „Flaschen gesamt" zählte Wunschliste- und „Nicht mehr da"-Lacke mit** — der Zähler neben „vorhanden" summierte über alle Status statt nur über tatsächlich besessene Lacke. (#182)

Alle vier: [#176](https://github.com/Mozra-the-great/nagellacke/issues/176), [#177](https://github.com/Mozra-the-great/nagellacke/issues/177), [#180](https://github.com/Mozra-the-great/nagellacke/issues/180), [#182](https://github.com/Mozra-the-great/nagellacke/issues/182).
