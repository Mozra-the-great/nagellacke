Pre-release for testing. Clears the entire open issue backlog (15 issues) and merges the 8 outstanding pull requests.

⚠️ **Two changes need attention before you deploy this.**

### Breaking: every account now has its own private collection (#87)

Until now the server kept one global `data.json` and every registered account read and wrote it — two accounts on the same server shared a collection, and `POST /api/sync/push` could replace another account's data outright. Collections now live at `data/users/<user>/data.json`.

On first start, the existing global `data.json` is **assigned to the first-registered account** and renamed to `data.json.pre-user-isolation`. Every other account starts with an empty collection and has to re-sync from a device that still holds its data locally. Nothing is deleted — the pre-migration file stays on disk.

### Sessions now expire after 7 days (#109)

Access tokens dropped from 30 days to 7, with a new refresh token and `POST /api/auth/refresh`. The web app refreshes silently, so you won't notice. **The Android app has no refresh logic yet**, so anyone who doesn't open it for more than a week will be asked to sign in again. Set `JWT_ACCESS_TTL` to restore the old window if that's a problem.

## New

- **Einkaufswagen tab with KI-Assistenz** (#86) — a cart for planned purchases, plus **KI Auto-Fill** (researches a polish's colour and finish in the background from just name/brand/number) and **Smart-Cart** (describe what's missing, the AI checks your collection, researches real products and adds validated hits). Provider is either **OpenRouter** (with a free-models-only switch) or **Gemini / Google AI Studio** directly, under Einstellungen → KI-Assistenz.
- **Global switch to turn all AI off** (#99) — Einstellungen → Darstellung. When off, nothing AI-related renders at all; it isn't greyed out, it's gone.
- **Android photo picker** (#89) — polish, sticker and diary forms can finally attach photos. `PhotoRepository.importPhoto()` had been fully implemented but unreachable from the UI. The unused `CAMERA` permission is gone from the manifest.

## Security

- Per-user data isolation (#87) and shorter sessions with a refresh flow (#109), both described above.
- Journal read access narrowed from the whole system journal to this one unit, via a validated sudoers rule instead of `systemd-journal` group membership (#110).
- Admin API key is now rotatable at runtime via `POST /api/admin/api-key/rotate`; the README documents both rotation paths (#108).
- Every `/api/*` route is rate-limited — eight were missing a limit, including two that read and write the AI config file.
- Merged from open PRs: GitHub Actions pinned to commit SHAs (#78), NodeSource installed from a signed apt repo instead of curl-pipe-bash (#75), CORS fails closed in production (#76), JWT revocation via `logout-all` (#77), and the admin key's trust boundary documented (#73).
- Dependency bumps: `@fastify/static` 10.1.2 (GHSA-8pvw-jcv7-9cmj, GHSA-83w8-p2f5-377r) and `fast-uri` 3.1.4 (GHSA-v2hh-gcrm-f6hx).

## Fixed

- Cross-origin `DELETE`/`PATCH` were silently blocked by CORS, so photo cleanup never reached a differently-hosted server and files quietly orphaned (#112).
- Weekly reports said "Wochesbericht" instead of "Wochenbericht" (#114).
- Deleting two items in quick succession dropped the first one's photo cleanup (#113).
- **Android**: editing an item no longer wipes fields the form doesn't show — bottle count and photos (#115).
- **Android**: sync now verifies its writes, and a failed *read* no longer falls back to "local wins", which could silently overwrite good remote data with one device's state; OAuth tokens refresh instead of going stale (#116).
- **Android**: edits made while a sync was in flight are no longer discarded (#88).
- **Android**: photos now display for Nextcloud, OneDrive and Dropbox, not just the "Server" provider; Google Drive shows an explicit "not supported" badge instead of silently falling back (#90).

### Testing notes

The server and web changes were exercised against a running build, not just typechecked — per-user isolation and its migration, the CORS preflight, the AI endpoints, the refresh flow, and rate-limit enforcement. Full monorepo build and core tests pass.

**The Android changes have not been compiled** — there was no Android SDK or Gradle toolchain in the environment they were written in. They were reviewed against the real class definitions, but please run a Gradle build before trusting the APK. Worth checking specifically: Coil 2.7's `ImageRequest.Builder.setHeader`, `PickVisualMediaRequest` resolution, and the assumption that Dropbox reports "file not found" as HTTP 409.

That's the main reason this is a pre-release rather than 3.2.0.
