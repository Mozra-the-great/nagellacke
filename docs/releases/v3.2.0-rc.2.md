Second pre-release. Same scope as `v3.2.0-rc.1`, plus one fix that matters if you intend to try the AI features.

### Why rc.2

rc.1 shipped the Einkaufswagen/KI feature in a state where **every AI job failed on a free-tier API key.** Both OpenRouter and Gemini bill web search separately from plain generation and neither includes it for free, but the code always asked for research — so Auto-Fill and Smart-Cart returned `429 quota exceeded`, and the error pointed at the API key rather than at the search add-on.

A grounded call that fails with 429/402 is now retried once without the search tool, answering from the model's own knowledge. Less reliable for obscure polishes than real research, but far better than the job failing outright. Any other error still propagates untouched.

Verified end-to-end against a live Gemini key with no grounding quota:

- **Auto-Fill** — Essie "Ballet Slippers" (162) → `{"color": "#f5e6e8", "finish": "Classic"}`
- **Smart-Cart** — the prompt from #86 ("Catrice ohne Shimmer/Sparkle, um den Regenbogen zu besitzen"), against a collection holding only red and blue, added exactly the five missing rainbow shades, all Catrice, all non-shimmer

Everything else is unchanged from rc.1 — see [its notes](https://github.com/Mozra-the-great/nagellacke/releases/tag/v3.2.0-rc.1) for the full list, **including the two deployment warnings** (per-account private collections, and 7-day sessions).

### Still untested

- **The OpenRouter path.** `openrouter.ai` was unreachable from the environment this was built in, so it has never been exercised. Two things to check before relying on it: `openrouter/free` does not look like a valid model slug (free variants are normally `vendor/model:free`), and with the free-models-only switch on, the default `openrouter/auto` becomes `openrouter/auto:free`, which is unlikely to resolve.
- **Grounded research itself**, which needs a key with web-search quota. Without it Smart-Cart is not verifying that a product genuinely exists — the one acceptance criterion from #86 that a free key can't satisfy.
- **The Android app has still not been compiled.** Unchanged from rc.1 and the main reason this is still a release candidate.
